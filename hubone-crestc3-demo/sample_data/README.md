# Demo 与验收素材

真实 CAD 数据位于 `space_intelligence/source/` 与 `space_intelligence/data/`，不依赖本目录媒体即可查看地图。

Crest C3 的 SIMULATED MP4/WAV 及场景记录由 `python scripts/generate_samples.py` 生成。独立真实录制参考素材由 `python scripts/prepare_acceptance_media.py` 准备；用途和来源见 V0.1 验收与 Windows 部署说明。模型下载使用 `scripts/download_models.py`。

生成媒体、运行数据库、模型权重与凭据不提交到源码分支；GitHub Pages 的 gh-pages 分支保留已经生成并明确标记的 SIMULATED 回放素材。
