## 修复的实际问题

1. 墙面与实体几何合并时的 UV 属性一致性。
2. 原二维指针事件与 OrbitControls 的冲突：按模式分流。
3. 公开预览新增 model 路由、bundle/CSS/许可文件，保留 `/hub-on/` 前缀与下载能力。
4. 页面旧缓存可能保留旧适配器：新增 v0.3 资源版本参数。
5. 窄屏改变相机宽高比后的横向裁切：重新计算正交取景范围。
6. 手机窄侧栏中建筑说明竖排：隐藏次要建筑卡，三维视口优先展示。
7. 2D/3D 同模拟摄像头 ID 的位置一致性。
8. 场景标注大小和光照色彩，减少区域颜色被过曝洗白。

## 未完成与未验证

- **尚不是核验后的完整 BIM**。墙柱分类为图层规则候选，缺少真实墙高、层高、标高、门窗高度、楼板孔洞及楼梯垂直剖面。
- 示意支撑楼板来自 50mm 栅格与 1m 半径缺口闭合的 CAD 线网重建，不是实测楼板或建筑面积；未知值仍为 null。
- 轴网对齐是 CAD 实例关系，未现场测量。二层 PDF 核对仍待正确文件：两份已上传 PDF 均显示一层。
- 没有实际摄像头清单、在线状态、视频流或 3000 路接入。真实人数、停留、轨迹、热力和体验反馈仍未连接。
- 运营演示与展台均为 SIMULATED，不是原始研究证据，不写入真实 Session。
- Windows/RTX 5070、现场设备和浏览器硬件加速环境未实机验收；提供可部署 bundle 和本地说明。
- GitHub Pages 只托管前端与授权的派生数据；完整上传、视觉/ASR/LLM 后端不在 Pages 运行。

以上限制在页面和数据中直接标记。准确三维建筑下一步需补充实测高度、楼板边界/孔洞、墙柱语义和设备标定，而不是增加虚构建筑体量。
