## 最终交互

只保留“建筑总览”和“内部空间”。取消独立的“楼层拆解”模式，复用原 Demo 视窗顶部的原生滑轨，0～100% 连续控制。轨道使用细线，触摸热区为 30px；百分比显示到 0.1%，固定宽度，不随数字变化挤动轨道，也不会把实际非零的 0.4% 显示为 0%。

滑轨在两个 3D 观察视图中均显示、可用。在总览开始拖动时，进入内部空间并保持当前观察方向。滑动过程中连续适配当前可见模型的相机范围，不切换相机预设、不重新加载模型。返回建筑总览时先归零，外壳与内部恢复正常对应。

分离按绝对位置计算：`二层展示 Y = 基准 Y + 进度 × 最大展示偏移`。一层保持基准位置。二层墙柱、楼板、洞口标线、辅助选取面随同一个楼层组移动；标签根据同一组的投影更新。配准引线原位更新缓冲，不反复创建几何。

## 三种状态与归零

下列单位为场景中的展示米制，**不是新的实测标高或建筑尺寸**。既有竖向字段与 CAD 数据没有改变。

| 滑轨 | 一层 Y | 二层 Y | 二层新增展示偏移 |
| --- | ---: | ---: | ---: |
| 0% | 0 | 4.2 | 0 |
| 50% | 0 | 70.7653125 | 66.5653125 |
| 100% | 0 | 137.330625 | 133.130625 |
| 往返后归零 | 0 | 4.2 | 0 |

0% 表示恢复原有楼层基准关系，不是把两个楼层压到同一高度。二层原有 4.2 的展示层距保持原样。

旧 V2.1 的最大展示偏移约 88.75375，已超过未分离模型约 13.2 的展示高度。因此直接使用模型高度的 1～1.5 倍会缩小旧间距。本次按“明显大于当前最大距离”的要求，将上限设为旧上限的 **1.5 倍**，约 133.130625；此值只用于展示。

202 次正向/反向采样、鼠标拖动及触摸拖动后，所有楼层世界矩阵与归零基准逐项完全相同，无累计坐标误差。模型实例、场景对象及几何 UUID 保持一致，滑动期间没有资源请求或模型重新加载。
