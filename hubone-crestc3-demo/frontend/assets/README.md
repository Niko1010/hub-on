# HUBONE brand assets

The three HUBONE SVG files contain original vector paths extracted from page 5 of the user's supplied **HUB ONE VIS.pdf**. The supplied brand mark and lettering have not been redrawn. The assets are used for the user's HUBONE interface; ownership remains with the original brand owner.

Roboto is downloaded from the Google Fonts `ofl/roboto` package. See `ROBOTO-OFL.txt` for its license. The complete brand PDF and its sample contact details are not part of the public site.
